MiMo Mini Agent Demo

这是一个不用 Python、也不用 Node.js 的小创意项目。 它模拟一个“任务拆解 Agent”：输入目标后，自动生成问题分析、任务分解、执行建议和风险提示。 适合直接放到 GitHub 上公开展示。

1单个文件即可运行
0后端依赖
100%浏览器打开即用

项目亮点

输入一句需求，输出一份结构化方案。演示“Agent 式工作流”：理解目标 → 分解任务 → 生成执行顺序 → 风险检查。

适合提交的场景

GitHub 公开仓库、GitHub Pages 演示页、创意项目展示、评审材料截图。

把这份代码保存成 index.html，上传到 GitHub 仓库根目录即可。
